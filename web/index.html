The thermal kernel is not built, so this room has no numbers. The geometry you see is real, and it is drawn by the same shader either way. What is missing is everything that MEASURES it: solar gain, AC draw, the curtain's SHGC and the room's temperature all come from the wasm module, and it is not in this checkout. dist/ is git-ignored (a build output), so a page served straight from a clone cannot have it; the preview you are looking at is exactly that case. Until then the room renders at its open-curtain appearance — no substitute temperature is invented, and the panel says — kernel not built rather than a number. Run npm run fetch:wasm, or cargo build --release --target wasm32-unknown-unknown -p odderon-dmath-wasm && cp target/wasm32-unknown-unknown/release/odderon_dmath_wasm.wasm dist/. If neither works here: fetch:wasm needs GitHub CLI credentials and the cargo path needs a Rust toolchain, so a sandboxed preview with neither can only show the geometry — which is exactly what this is.
