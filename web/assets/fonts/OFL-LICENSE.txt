Odderon bundles the following typefaces. All three are licensed under the
SIL Open Font License, Version 1.1, which permits redistribution inside a
game build. The fonts are shipped as local WOFF2 files, never fetched from a
third-party service, so the game stays playable offline and packageable for a
desktop or Steam build without changing the code.

  Barlow Condensed   Copyright (c) 2017 The Barlow Project Authors
                     https://github.com/jpt/barlow
  IBM Plex Mono      Copyright (c) 2017 IBM Corporation
                     https://github.com/IBM/plex
  Rajdhani           Copyright (c) 2014 Indian Type Foundry
                     https://github.com/itfoundry/rajdhani

Files in this directory are subsets of the "latin" unicode range produced by
@fontsource. Obtain the full OFL text and the original font sources from the
projects above.
